蓍草揲卦法

大衍之数五十，其用四十有九

《周易》原始的占筮方法，以五十根蓍草经三变成一爻、十八变成一卦，过程严谨而富有仪式感，是最正统的起卦之法。

蓍草法的地位

蓍草揲卦法记载于《周易·系辞上传》：

「大衍之数五十，其用四十有九。分而为二以象两，挂一以象三，揲之以四以象四时，归奇于扐以象闰。五岁再闰，故再扐而后挂。」

这是《周易》中唯一明确记载的占筮方法。相比铜钱法，蓍草法更古老、更正统，且阴阳概率分布更接近《周易》的本意：老阳概率 1/16，老阴概率 3/16，少阳概率 5/16，少阴概率 7/16——阳爻变化少而珍贵，阴爻变化多而寻常。

准备工作

取蓍草五十根（可用竹签、筷子等代替），抽出一根放在一旁不用，实际操作四十九根。

传统上需焚香净手、面南而坐，心中默念所问之事。

工具： 49根蓍草（或替代物） 场地： 安静整洁的桌面 心态： 诚敬专注，一事一问

三变成一爻

每一爻需要经过「三变」才能得出，具体步骤：

第一变： 1. 将49根蓍草随机分成左右两堆（分二以象两） 2. 从右堆取出1根，夹在左手小指间（挂一以象三） 3. 左手拿左堆，每4根一数地数完（揲之以四以象四时） 4. 将余数（1—4根）夹在左手无名指间（归奇于扐） 5. 同样对右堆每4根一数，余数夹在中指间（再扐而后挂） 6. 第一变所夹之数必为 5 或 9

第二变： 将夹出的蓍草放在一旁，剩余蓍草（44 或 40 根）重复上述分二、挂一、揲四、归奇的过程。第二变所夹之数为 4 或 8。

第三变： 再将夹出的放在一旁，剩余蓍草重复一次。第三变所夹之数也为 4 或 8。

三变后，将剩余蓍草除以4，得到的数字决定爻的性质。

判定爻象

三变后剩余的蓍草数只有四种可能：

剩余数除以4爻象性质
369老阳 ⚌阳爻，变爻
328少阴 ⚎阴爻，不变
287少阳 ⚍阳爻，不变
246老阴 ⚏阴爻，变爻

从初爻（最下）到上爻（最上），重复六次「三变」，共十八变，即可得到完整的六爻卦。

与铜钱法的区别

概率差异： 蓍草法中，四种结果的概率并不均等： - 老阳（9）：1/16 = 6.25% - 少阴（8）：7/16 = 43.75% - 少阳（7）：5/16 = 31.25% - 老阴（6）：3/16 = 18.75%

铜钱法中，概率分布为： - 老阳（9）：1/8 = 12.5% - 少阴（8）：3/8 = 37.5% - 少阳（7）：3/8 = 37.5% - 老阴（6）：1/8 = 12.5%

蓍草法的阳爻概率（少阳+老阳 = 37.5%）低于阴爻（62.5%），而铜钱法阴阳各半。这意味着蓍草法中阳爻更「珍贵」，变爻出现的概率更低——与《周易》强调阳动阴静的哲学更一致。

仪式感： 蓍草法过程庄重缓慢（约需二十分钟），本身就是一种静心冥想的过程。铜钱法则简便快捷，适合日常使用。
