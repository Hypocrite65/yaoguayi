梅花易数

邵雍心易，万物皆可起卦

北宋邵雍所创的简易占法，不需蓍草铜钱，以数字、时间、所见所闻皆可起卦，强调「心易」——心念一动即成卦象。

梅花易数的由来

北宋理学家邵雍（字尧夫，1011—1077），与周敦颐、张载、程颢、程颐并称「北宋五子」，是象数易学的集大成者。其代表作《皇极经世》以先天易学为基础，构建了宏大的宇宙历史体系。

相传邵雍某日观梅，见二雀争枝坠地，心有所感，遂以当时年月日时之数起卦，得泽火革卦，变为泽山咸卦。据此推断次日黄昏将有女子折花坠伤，后果然应验。此事成为梅花易数的起源故事。

梅花易数代表了占卜方式从「依赖实物工具」到「纯粹心意数理」的重大转变。蓍草法需四十九根蓍草，铜钱法需三枚铜钱，而梅花易数不需任何工具——随时随地，以数字、时间、所见所闻皆可起卦，强调「心易」——心念一动即成卦象。

基本原理

梅花易数的起卦方法有多种，但核心逻辑一致：

1. 取数成卦 将获得的数字分别除以8取余，对应八卦： 余1=乾，余2=兑，余3=离，余4=震 余5=巽，余6=坎，余7=艮，余0(8)=坤

2. 上卦 + 下卦 → 本卦 两个数字分别确定上卦和下卦，组成六画卦。

3. 求动爻（变爻） 将特定数字除以6取余，余数即为动爻位置（余0则为第6爻）。动爻所在的爻阴阳互变，得到变卦。

4. 断卦 以本卦的体用关系（动爻所在为用卦，不动为体卦）结合五行生克来判断吉凶。

常用起卦方法

一、时间起卦 以年支序数 + 月 + 日之和除以8，余数为上卦； 年支序数 + 月 + 日 + 时辰序数之和除以8，余数为下卦； 上述总和除以6，余数为动爻。

例：甲子年三月十五日午时 甲子=1，上卦=(1+3+15)÷8，余3=离 下卦=(1+3+15+7)÷8，余2=兑 本卦：火泽睽 动爻=(1+3+15+7)÷6，余2=第二爻动

二、报数起卦 请问卦者随意说两个数字，分别作上下卦；两数之和除以6定动爻。

三、物象起卦 根据所见事物的先天八卦属性起卦。如见老人（乾）在湖边（兑），上乾下兑=天泽履。再以所见之数定动爻。

四、文字起卦 以汉字笔画数起卦。单字以笔画数除以8定卦；两字则前字定上卦，后字定下卦；多字取前半定上卦，后半定下卦。

体用与断卦

梅花易数的独特之处在于体用学说：

体卦：动爻不在其中的三画卦（代表自己、主体） 用卦：动爻所在的三画卦（代表对方、客体、事态）

断卦时以五行生克为核心： - 用生体：吉，外来助力 - 体生用：凶，精力外泄 - 体克用：吉，能掌控局面 - 用克体：凶，受制于人 - 体用比和：吉，和谐顺遂

再参考卦象、爻辞、互卦（本卦二三四爻为下互卦，三四五爻为上互卦）综合判断。

与蓍草法、铜钱法的比较

蓍草法：最古老正统，过程庄重，需专门工具，耗时约二十分钟。概率分布最符合《周易》本意。

铜钱法：简便实用，三枚铜钱即可，几分钟完成。是最流行的起卦方式。

梅花易数：最灵活，无需任何工具，随时随地可起卦。但对断卦者的悟性和经验要求最高——同一个卦象，不同人可能有不同解读。

三种方法各有特色：蓍草法重「礼」，铜钱法重「简」，梅花易数重「心」。传统学习路径多从铜钱法入手，熟悉卦象后再学梅花易数，有条件者亦可尝试蓍草古法以体会《周易》原意。
