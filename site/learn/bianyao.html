变爻断卦法

朱熹《易学启蒙》七条规则

卜筮得卦后，根据变爻（老阳、老阴）的数量，决定应该看哪段经文来解卦。这是实际占卜中最核心的判断方法。

什么是变爻？

卜筮时，每一爻通过铜钱或蓍草得出，有四种可能的结果：

老阳（三个正面）— 阳爻，但物极必反，会变为阴爻 → 这就是「变爻」 少阳（两正一反）— 阳爻，稳定不动 少阴（一正两反）— 阴爻，稳定不动 老阴（三个反面）— 阴爻，但物极必反，会变为阳爻 → 这也是「变爻」

简单说：「老」的爻会变化，「少」的爻保持不动。变爻是解卦的关键线索。

本卦与变卦

本卦：卜筮直接得到的卦象，反映事情的当前状态。

变卦：把本卦中所有变爻的阴阳翻转后得到的新卦，反映事情的发展趋势。

举例：卜得「乾」卦（六个阳爻），其中第三爻是老阳（要变），将第三爻从阳变为阴，得到「天泽履」卦——这就是变卦。

本卦看现在，变卦看未来。

七条断卦规则

得到本卦和变卦后，关键问题是：应该看哪段经文来回答我的问题？

朱熹在《易学启蒙》中提出了七条规则：

一、无变爻（六爻全是「少」） → 看本卦的卦辞 例：卜得乾卦，无变爻 → 看「元，亨，利，贞」

二、一个变爻 → 看本卦中那个变爻的爻辞 例：乾卦第五爻变 → 看九五「飞龙在天，利见大人」

三、两个变爻 → 看两个变爻的爻辞，以位置较高的为主 例：第二爻和第五爻变 → 看九二和九五，以九五为主

四、三个变爻 → 看本卦卦辞和变卦卦辞，以本卦为主 本卦反映当前，变卦反映趋势，综合判断

五、四个变爻 → 反过来看变卦中两个不变爻的爻辞，以下面的为主 变的太多时，「不变」的爻反而是关键锚点

六、五个变爻 → 看变卦中唯一不变的那个爻的爻辞 几乎全变，唯一稳定的爻就是核心信息

七、六爻皆变 → 乾卦看「用九：见群龙无首，吉」 → 坤卦看「用六：利永贞」 → 其余卦看变卦的卦辞

断卦实例

实例：铜钱起卦得一个变爻

假设摇卦六次，结果如下： 第一爻（初爻）：一正两反 = 7 → 少阳 ⚍（不变） 第二爻（二爻）：两正一反 = 8 → 少阴 ⚎（不变） 第三爻（三爻）：一正两反 = 7 → 少阳 ⚍（不变） 第四爻（四爻）：三正 = 9 → 老阳 ⚌（变爻！） 第五爻（五爻）：两正一反 = 8 → 少阴 ⚎（不变） 第六爻（上爻）：一正两反 = 7 → 少阳 ⚍（不变）

排出本卦： 从下到上为 阳阴阳阳阴阳，即 ☲下☲上 = 离为火（第30卦）

找出变卦： 第四爻老阳变阴，得到 阳阴阳阴阴阳 = ☲下☵上 = 火水未济（第64卦）

应用七条规则： 只有一个变爻（第四爻），适用规则二——看本卦变爻的爻辞，即离卦九四爻辞： 「突如其来如，焚如，死如，弃如。」

这就是完整的从起卦到找对经文的过程。关键在于： · 先数变爻个数，确定用哪条规则 · 再根据规则找到应看的卦辞或爻辞 · 最后结合所问之事进行理解

规律总结

变爻少（0—3个）→ 重点看本卦 变爻多（4—6个）→ 重点看变卦

变爻是运动的方向，不变爻是稳定的根基。变爻少时，变化是局部的，本卦的整体格局更重要；变爻多时，局面正在大幅转变，变卦所指的方向才是重点。

这也是为什么《周易》每一卦不仅有卦辞（整卦总论），还有每一爻的爻辞——它们各自对应不同的卜筮结果。
