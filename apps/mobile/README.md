# 爻卦易 · 移动端（规划中）

> 本目录为 **Phase 2** 内容，待 Web 版本稳定后启动。

## 技术方案

- **React Native + Expo** — 复用 `@yaoguayi/iching-core` 和 `@yaoguayi/iching-data`
- **NativeWind** — Tailwind 风格的 RN 样式
- 目标平台：iOS 16+ · Android 10+

## 发布计划

- App Store（免费，无内购）
- Google Play（免费，无内购）

如你有 React Native 经验，欢迎通过 Issue 参与讨论移动端架构设计。
